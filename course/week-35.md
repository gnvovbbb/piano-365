# Тиждень 35 — Dream Piece I: повільна збірка першої половини

**Дні 239–245**

## Мета
Зібрати першу половину твору в одну контрольовану форму, не женучись за оригінальним темпом.

---

## День 239 — Карта першої половини

Запиши на папері/в нотатках:
A → B → C? залежно від аранжування.

Для кожної секції:
- стартова harmony;
- start note;
- texture;
- dynamic;
- checkpoint.

### Mental run
Без piano пройди форму в голові.

### Piano
Стартуй із кожної секції по 2 рази.

**Готово, якщо:** можеш почати з будь-якої секції першої половини.

---

## День 240 — Слабша секція №1

Оціни A/B/C:
яка найслабша?

Сьогодні 70% practice — їй.

### 20-min repair
- hardest 1–2 bars;
- transition in;
- transition out;
- one section run.

### Заборона
Не витрачай більшість часу на section, яка вже комфортна.

---

## День 241 — Balance day

У першій половині:
- accompaniment p;
- melody mf;
- inner notes softer.

### Exercise
Зіграй melody alone.
Потім accompaniment alone тихо.
Потім together.

### Camera
30–45 sec side recording.

Слухай, чи melody губиться в кульмінаційних місцях.

---

## День 242 — Tempo ladder першої половини

Визнач base tempo, де вся перша половина майже чиста.

Наприклад:
50 BPM.

### Ladder
50 → 54 → 58 → 62.

На кожному:
1 clean section transition мінімум.

Якщо два breakdowns — назад.

### Rule
Не тренуй тільки fastest attempt.

Закінчи на tempo, де можеш красиво.

---

## День 243 — Pedal day

Грай першу половину:
1. dry;
2. із pedal map.

### Послухай
- bass mud;
- harmony changes;
- release before new section;
- climax clarity.

### Mark
У score/notes познач:
P = change;
0 = dry/clear;
L = longer resonance.

---

## День 244 — First-half no-stop run

Warmup 8 хв.

Потім:
**один** run першої половини без stop.

Навіть якщо:
- пропустив inner note;
- chord неповний;
- minor stumble.

Збережи pulse.

### Після
Виправ лише 2 найбільші проблеми.

---

## День 245 — First-half checkpoint

### Test
1. 3 random start points.
2. A→B transition.
3. B→next transition.
4. full first-half run.
5. 30 sec from memory without score if appropriate.

### Score 0–2
- form;
- memory;
- tempo;
- voicing;
- pedal.
