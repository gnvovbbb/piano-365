# Тиждень 08 — Педаль і акомпанемент

**Дні 50–56**

## Результат тижня
Ти:
- розумієш, навіщо sustain pedal;
- міняєш педаль після зміни гармонії;
- чуєш «чисто» проти «каша»;
- граєш block / bass+chord / broken chord;
- записуєш перший акомпанемент, який звучить цілісно.

## Головне правило педалі
Базовий варіант:
1. зіграй новий акорд;
2. одразу після атаки опусти педаль;
3. при наступному акорді підніми стару педаль;
4. зіграй новий акорд;
5. знову опусти педаль.

Тобто педаль **реагує на гармонію**, а не натискається назавжди.

---

## День 50 — Перша педаль

### Без музики
Зіграй C major.
Після атаки опусти sustain pedal.
Відпусти руки — акорд продовжує звучати.

Підніми педаль — звук гасне.

Повтори 10 разів.

### Координація
Не натискай педаль раніше акорду.
Спробуй:
- chord;
- pedal;
- руки вгору;
- pedal up.

### Слух
Зверни увагу на механічний шум педалі.
Не кидай її різко.

**Готово, якщо:** можеш свідомо ввімкнути й вимкнути резонанс.

---

## День 51 — Зміна педалі C→F

### Спочатку без педалі
C 4 долі.
F 4 долі.

### Потім педаль
На C — pedal down після атаки.

На переході:
- педаль вгору;
- F звучить;
- педаль вниз.

Роби дуже повільно.

### Тест на «кашу»
Навмисно **не міняй** педаль між C і F.
Послухай змішування.

Потім зроби правильно.

**Готово, якщо:** на слух чуєш різницю.

---

## День 52 — C→F→G→C з педаллю

### 1. Block chords
Один акорд = одна pedal cycle.

### 2. 8 циклів
45–55 BPM.

### 3. Руки
RH акорди.
LH roots окремо.

### 4. Разом
LH root + RH chord.
Pedal change на гармонію.

Не намагайся одночасно думати про 10 речей.
Пріоритет:
1. correct chord;
2. clean pedal;
3. pulse.

**Готово, якщо:** 4 акорди проходять без чутної гармонічної каші.

---

## День 53 — Broken chord 1–5–3–5

У C:
C-G-E-G.

У Am:
A-E-C-E.

У F:
F-C-A-C.

У G:
G-D-B-D.

### LH
Повільно по 4 ноти на акорд.

### Pedal
Одна pedal cycle на один акорд.

### RH
Поки лише довгі melody notes.

### Ритм
Чотири рівні чверті або восьмі на дуже повільному темпі — залежно від комфорту.

**Готово, якщо:** pattern рівний, а кисть не застигає.

---

## День 54 — Три акомпанементи

На progression C-Am-F-G зіграй:

### A. Block
Один chord на такт.

### B. Bass + chord
Root → chord.

### C. Broken
1–5–3–5.

Запиши по 20 секунд кожного.

Порівняй:
- який найстабільніший?
- який звучить найбільш «піаністично»?
- де LH занадто гучна?

**Готово, якщо:** можеш свідомо змінити texture, не змінюючи harmony.

---

## День 55 — Easy Win

Обери просту мелодію або власний мотив.

### План
1. RH melody — чисто без педалі.
2. LH progression — чисто без RH.
3. Разом без педалі.
4. Педаль лише після того, як руки стабільні.
5. Додай p→mf у середині.

### Performance prep
Створи 3 start points:
- початок;
- середина;
- останній акорд/фраза.

**Готово, якщо:** можеш стартувати не тільки з початку.
