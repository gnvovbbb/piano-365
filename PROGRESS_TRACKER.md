# Progress Tracker

## Щотижневий чек
Постав 0, 1 або 2:
- Ритм
- Чистота нот
- Координація
- Розслаблення
- Педаль
- Динаміка
- Читання
- Слух
- Акорди / гармонія
- Пам'ять

**0** = нестабільно або поки не розумію  
**1** = виходить повільно / частково / після кількох спроб  
**2** = стабільно в поточному матеріалі

Не потрібно мати 2 у всіх категоріях щотижня.

## Щомісячний запис
Наприкінці кожних 4 тижнів:
1. одна підготовлена композиція або завершений фрагмент;
2. 60 секунд поточної техніки;
3. коротка ear-вправа відповідного рівня;
4. 30–60 секунд імпровізації, коли вона вже введена в курс;
5. короткий коментар: що стало легше, що системно заважає.

## Як використовувати оцінки
Якщо категорія має **0**:
1. не повертайся автоматично на кілька тижнів назад;
2. додай 5–10 хв цієї навички у наступні заняття;
3. через 7–14 навчальних днів повтори конкретний тест;
4. якщо є фізичний біль — не «наздоганяй» курс.

День курсу — це **номер навчального заняття**, а не обов'язково календарна дата.
