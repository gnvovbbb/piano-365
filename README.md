# Piano 365 🎹

Повний 365-денний курс фортепіано для дорослого початківця, який хоче за рік:
- впевнено грати двома руками;
- читати базові ноти та lead sheets;
- розуміти акорди й гармонію;
- підбирати прості мелодії та гармонію на слух;
- імпровізувати в знайомих тональностях;
- користуватися педаллю, динамікою та фразуванням;
- зібрати власний концертний набір;
- підготувати красиву версію музики рівня **Interstellar**.

## Формат

Курс розрахований на 45–60 хв практики 5–6 днів на тиждень, але містить режим **Minimum 20** для дуже зайнятих днів.

Кожен із 365 днів має:
1. розігрів;
2. технічну вправу;
3. слух / ритм / теорію;
4. роботу над репертуаром;
5. коротке творче завдання;
6. критерій виконання.

## Інтерактивна веб-версія

У репозиторії є повноцінний статичний веб-додаток:
- відкриває потрібний День 1–365;
- читає уроки напряму з Markdown-файлів курсу;
- зберігає виконані дні, streak, нотатки та хвилини практики в браузері;
- має таймер 20/45/60 хв;
- має вбудований метроном 40–220 BPM;
- має базовий ear trainer «вище / нижче / та сама нота»;
- показує карту всього року та прогрес по 12 фазах;
- дозволяє експортувати та імпортувати прогрес JSON-файлом;
- працює як PWA та кешує вже відкриті матеріали.

GitHub Actions у `.github/workflows/pages.yml` публікує сайт через GitHub Pages, а `.github/workflows/validate.yml` перевіряє цілісність курсу й JavaScript.

## Головне правило

Не переходь до швидкості, доки рух не став чистим. Якщо складне місце не виходить:
- сповільни його;
- зіграй окремими руками;
- розбий на 1–2 такти;
- зроби 3 чисті повтори;
- тільки потім прискорюй.

## Режими заняття

### Full — 60 хв
- 10 хв техніка
- 10 хв слух/ритм/читання
- 30 хв репертуар
- 10 хв імпровізація/повторення/запис

### Standard — 45 хв
- 8 хв техніка
- 7 хв слух
- 25 хв репертуар
- 5 хв творчість

### Minimum 20
- 5 хв техніка
- 5 хв слух або читання
- 10 хв найважче місце поточної композиції

Навіть у Minimum 20 день вважається виконаним, якщо ти свідомо попрацював, а не просто "пограв".

## Запис прогресу

Щонеділі або в останній день тижня:
- запиши 1 відео без зупинок;
- оцінюй ритм, чистоту, напруження, динаміку та музикальність;
- запиши одну проблему, яку виправиш наступного тижня.

## Важливо

Курс не замінює викладача для виправлення індивідуальної постановки рук. Якщо з'являється біль, оніміння або стійке напруження — припини вправу й перевір техніку.

Ноти сучасних захищених авторським правом композицій у репозиторії не публікуються. Для конкретних творів використовуй легальні ноти або власний підбір на слух.
