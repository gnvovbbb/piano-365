# Локальний запуск Piano 365

Веб-додаток використовує `fetch()` для читання Markdown-уроків, тому подвійний клік по `index.html` через `file://` у деяких браузерах не дозволить завантажити уроки.

Потрібен маленький локальний HTTP-сервер.

## Windows — найпростіше
1. Клонуй/завантаж репозиторій.
2. Запусти `start-local.bat`.
3. Відкриється:
   `http://localhost:8000/`
4. Щоб зупинити сервер, натисни **Ctrl+C** у вікні консолі.

Скрипт автоматично пробує:
1. Python Launcher `py`;
2. `python`;
3. `npx http-server`.

## Вручну через Python
У папці репозиторію:

```powershell
py -m http.server 8000
```

або:

```powershell
python -m http.server 8000
```

Потім відкрий `http://localhost:8000/`.

## Через Node.js
```powershell
npx http-server . -p 8000 -c-1
```

## Де зберігається прогрес
Виконані дні, нотатки та статистика зберігаються у `localStorage` конкретного браузера.

Тому:
- `localhost:8000` і GitHub Pages — це різні сховища;
- перед переходом між ними натисни **Експорт** у вкладці «Статистика»;
- на іншій версії натисни **Імпорт** і вибери JSON.

## Мікрофон
Practice Recorder найнадійніше працює:
- на GitHub Pages через HTTPS;
- або на `localhost`, який сучасні браузери вважають безпечним локальним контекстом.

Браузер попросить доступ до мікрофона тільки після натискання «Почати запис».
